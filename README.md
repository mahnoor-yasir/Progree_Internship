# Task 03 — AERIS Weather Portal

<div align="center">

### AERIS

**Intelligent Weather Portal**

</div>

The third task focused on building an asynchronous weather application using a real REST API.

AERIS retrieves weather information from OpenWeatherMap and transforms the API responses into a responsive weather dashboard.

The project demonstrates practical API communication, asynchronous JavaScript, error handling, data transformation, browser storage, geolocation, responsive design, and dynamic UI rendering.

### Core Features

<table>
<tr>
<td width="33%" align="center">

### Current Weather

Temperature, feels-like temperature, humidity, wind, pressure, visibility, clouds, sunrise and sunset.

</td>

<td width="33%" align="center">

### Forecast

Hourly weather information, temperature trends and multi-day forecast.

</td>

<td width="33%" align="center">

### Location

City search, geolocation, recent searches and favourite locations.

</td>
</tr>

<tr>
<td align="center">

### Units

Celsius/Fahrenheit and multiple wind-speed units.

</td>

<td align="center">

### Themes

Light, dark and system theme preferences.

</td>

<td align="center">

### Persistence

LocalStorage-based preferences, history, favourites and caching.

</td>
</tr>
</table>

### API Integration

The application uses OpenWeatherMap services for:

* Current weather
* Forecast
* Geocoding
* Reverse geocoding
* Optional air-quality information

### Asynchronous Architecture

The application uses modern JavaScript techniques including:

```text
Fetch API
async / await
Promises
Promise.all()
AbortController
```

Current weather and forecast requests can be loaded concurrently through `Promise.all()`.

### Error Handling

The application handles:

* Missing API key
* Invalid API key
* Unknown location
* Network errors
* Request timeout
* API rate limits
* Server errors
* Geolocation errors
* Optional API failures

### Performance Features

* Client-side weather caching
* Duplicate request protection
* Request timeout
* Optional automatic refresh
* Visibility-aware refresh behaviour
* Lightweight SVG visualization

### Responsive Experience

The weather dashboard adapts across mobile, tablet, laptop, and desktop layouts.

# Performance & Reliability

The projects include several practical techniques to improve frontend reliability.

### API Timeout Handling

Long-running weather requests can be cancelled using `AbortController`.

### Client-Side Caching

Weather information can be cached temporarily to reduce unnecessary API requests.

### Duplicate Request Protection

Repeated actions can be prevented while an existing request is still running.

### Defensive Rendering

Missing API values are handled gracefully rather than allowing undefined values to break the interface.

### Responsive Optimization

Layouts adapt according to viewport dimensions rather than relying on fixed desktop-only dimensions.
